Como usar
  1. Deixe o computador e o celular na mesma rede Wi-Fi.
  2. Inicie o backend com --host 0.0.0.0 (veja o comando abaixo).
  3. Escaneie o QR Code com a câmera do celular e toque no link.
  4. Se não abrir, libere a porta 8000 no firewall do Windows (aviso que aparece ao iniciar o servidor).
cd AutoSetup_estrutura\backend
python -m uvicorn api.main:app --host 0.0.0.0 --port 8000
